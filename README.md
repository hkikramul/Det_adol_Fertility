# Det_adol_Fertility

Research on adolescent childbearing in Bangladesh.

## Revised BDHS 2022 analysis

The reproducible analysis for ever-married adolescents aged 15–19 is in [BDHS_Adolescent_Childbearing](BDHS_Adolescent_Childbearing/README.md).

- [Revised manuscript (PDF)](BDHS_Adolescent_Childbearing/manuscript/Manuscript_Revised.pdf)
- [Editable LaTeX manuscript](BDHS_Adolescent_Childbearing/manuscript/Manuscript_Revised.tex)
- [Analysis scripts](BDHS_Adolescent_Childbearing/scripts/)
- [Aggregate results](BDHS_Adolescent_Childbearing/results/)
- [Completed and outstanding statistical checks](BDHS_Adolescent_Childbearing/docs/analysis_status.md)

This is a research-review release. Independent R verification and resolution of questionnaire subsample weighting remain necessary before submission. The cross-sectional findings describe associations and do not establish causal effects.

Earlier files remain available at the repository root. The revised package does not include raw DHS respondent data. Obtain authorized data separately and follow DHS access conditions.
